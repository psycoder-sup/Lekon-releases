Lekon 0.3.2

Tags replace contexts and labels

  • Contexts and labels are now one thing: Tags. A single type-in chip on every stage, on the clarify card and in Quick Capture — start a name with @ and it reads as a context, anything else is a label. Nothing to pick, nothing to convert; your existing contexts and labels are already tags
  • Settings manages all of them in one place — rename or delete
  • CLI heads-up: lekon context … is retired in favour of lekon tag list|add|rm|rename, and the context grammar becomes a repeatable --tag. The old commands now fail with a message naming their replacement rather than silently doing something else

The app keeps up with the CLI

  • A task added by lekon add — or by Claude through the MCP server — now shows up in an already-open window in well under a second. No navigating away and back, no relaunch
  • Switching back to Lekon from another app also refreshes every list, which covers anything that wrote to your store while Lekon was in the background

Claude can drive Lekon

  • New lekon-mcp server hands your tasks and projects to Claude Code and Claude Desktop directly
  • Settings has an Install MCP server row — pick the client and it registers itself, merging into your existing config instead of overwriting it

Clarify

  • Type a project or tag name that doesn't exist yet, press ⏎, and it's created and assigned on the spot — on the clarify card, the Calendar row, and the Next Actions / Waiting For / Someday / Reference project fields
  • A clarify card's note is now editable in place
  • Clicking outside an open PROJECT or TAGS dropdown closes it, and your click still lands where you aimed it

Inbox gauge

  • "INBOX PROCESSED" now tracks a day rather than a session: it resets at midnight, re-bases on whatever is still in your inbox, and survives a restart — so quitting the app at lunch no longer wipes the morning's progress

Fixes

  • Waiting For: an all-day due date never counted as overdue, however long past it was. Date-only due dates now read correctly
  • The DEFER pill in Quick Capture and lekon add --defer have been withdrawn. A defer date has never affected any list, so both were reporting success and changing nothing; they'll return when there's a real design behind them
  • lekon project rm --cascade deletes a project's tasks along with it. Plain rm still keeps them and just clears the project
